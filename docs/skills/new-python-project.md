# New Python project bootstrap

The [bootstrap guide](../../.claude/skills/new-python-project/README.md)
describes the skill for generating a new project from this blueprint. It uses
Python 3.13+, the locked Template Press release, and the pinned Bun version.

The bootstrap validates the generated CLI and web application before opening
an initialization pull request. Its template-only skill is retired after
rebranding. Continue repository and service configuration with the retained
[project setup checklist](../PROJECT_SETUP.md).
